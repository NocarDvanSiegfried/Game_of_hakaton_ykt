## 2. ОПИСАНИЕ СЦЕНЫ

### 2.1. Общая композиция

Огромный ледяной колодец (~20 м в диаметре), уходящий в бесконечную глубину. Края — неровный, потрескавшийся лёд с осколками разбитых зеркал. Внутри колодца кружатся светящиеся нити — мысли, сны, молитвы, формулы. Они закручиваются в гигантскую спираль. В центре, глубоко внизу — огромный Глаз с переливающейся радужкой. На переднем плане, на краю — три маленькие фигурки героев с золотистым свечением.

### 2.2. Ледяной колодец

| Параметр | Описание |
|:---------|:---------|
| **Диаметр** | ~20 метров. Края от левого до правого края экрана. |
| **Глубина** | Бесконечная. Стенки уходят вертикально вниз. |
| **Стенки** | Спрессованные слои льда с вмороженными обрывками реальности: страницы, лица, ткань, зеркала, часы, ключи, игрушки. Всё медленно движется вниз по спирали. |
| **Края** | Неровные, тёмно-синие, почти чёрные. Острые сколы, как битое стекло. |

### 2.3. Нити мыслей

Светящиеся нити разной толщины кружатся по спирали внутри колодца:

| Цвет | Значение |
|:-----|:---------|
| Золотые | Надежды и мечты — самые яркие |
| Синие | Печаль и воспоминания |
| Красные | Страсть, гнев, любовь — пульсирующие |
| Белые | Забытые мысли — тающие |
| Фиолетовые | Вопросы без ответов — мерцающие |

В некоторых нитях можно разглядеть образы: детская молитва, забытая формула, непроизнесённое признание в любви, последняя мысль умирающего.

### 2.4. Глаз *(центр колодца)*

| Параметр | Описание |
|:---------|:---------|
| **Размер** | ~180 см в диаметре — почти с человеческий рост. |
| **Радужка** | Переливается как северное сияние: изумрудный, фиолетовый, бирюзовый, розовый, золотой. |
| **Зрачок** | Вертикальный, постоянно меняет форму — круглый, квадратный, треугольный, несколько маленьких. |
| **Белок** | Перламутровый, с серебристым свечением. В нём отражаются нити. |
| **Веки** | Отсутствуют. Не моргает. Гипнотический эффект. |
| **Выражение** | Невозможно прочитать. Взгляд вечности — спокойный и непостижимый. |

### 2.5. Осколки зеркал *(на краях)*

Десятки осколков, от маленьких до больших (в человеческий рост). Не отражают героев — показывают альтернативные жизни: Айсен с живым отцом, Кюннэй на сцене, Баргый-волк, Айсен замёрзший, Кюннэй в Теневом Кармане, молодая Бабушка с мужем.

### 2.6. Освещение

Свет из глубины колодца (нити + Глаз) — холодный, переливающийся, снизу вверх. Ртутные блики от зеркал. Золотистое свечение героев — единственный тёплый свет.

## 3. АТМОСФЕРА

| Аспект | Описание |
|:-------|:---------|
| **Головокружение** | Нет верха и низа, нет направления, нет времени. Только кружащиеся мысли и Глаз, смотрящий в тебя. |
| **Психоделика** | Самая яркая цветовая гамма в игре — взрыв холодного цвета (как северное сияние). |
| **Притяжение бездны** | Глаз гипнотизирует. Хочется прыгнуть — не из отчаяния, из любопытства. Что там, на дне? |
| **Символизм** | Первозданный хаос, из которого родился мир. Глаз — сам Водоворот, наблюдающий за творением. |

## 5. ДЕТАЛИ ДЛЯ ХУДОЖНИКА

### 5.1. Обязательные элементы

- Огромный ледяной колодец
- Светящиеся нити мыслей, кружащиеся по спирали (разных цветов)
- Глаз в центре с переливающейся радужкой и меняющимся зрачком
- Осколки зеркал с альтернативными жизнями
- Маленькие фигурки героев с золотистым свечением
- Вмороженные обрывки реальности в стенах

### 5.2. Дополнительная вариация *(после инициации)*

Водоворот затихает. Нити останавливаются. Глаз закрывается или исчезает. Колодец превращается в спокойное зеркальное озеро.
