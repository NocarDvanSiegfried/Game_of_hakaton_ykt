## Цель

Перед главным меню показывать intro-видео с титрами:

- SAAS STUDIO

- Путь сквозь Лёд

## Поведение

### Цепочка запуска

```
Запуск игры (F5 / exe)
    → intro.tscn
    → (видео / пропуск / ошибка)
    → main_menu.tscn  ← как раньше была main_scene
    → Новая игра → main.tscn → Dialogic
```

Возврат из игры в меню **не** проигрывает intro повторно (меняется только `run/main_scene`).

### Автозапуск видео

В `_ready()`:

1. Проверка `ResourceLoader.exists(intro.ogv)`
2. Загрузка через `load()` или `VideoStreamTheora`
3. `VideoStreamPlayer.play()`

### Пропуск заставки

| Ввод | Поддержка |
|------|-----------|
| Enter | да (`ui_accept`, KEY_ENTER) |
| Space | да |
| Esc | да (`ui_cancel`, KEY_ESCAPE) |
| ЛКМ | да |
| Touch / tap | да (`InputEventScreenTouch`) |

### Защита от зависания

| Ситуация | Действие |
|----------|----------|
| Файл не найден | Сразу `main_menu.tscn` |
| Видео не начало играть за 4 с | Переход в меню |
| `finished` не пришёл | Таймаут по длительности ролика + 2 с (макс. 180 с) |
| Двойной переход | Флаг `_is_transitioning` |

### Защита от двойного перехода

Все пути (конец видео, пропуск, таймауты) вызывают один метод `_go_to_next_scene()`, который выходит при `_is_transitioning == true`.

## Ручная проверка (чеклист)

- [ ] Запуск проекта — сначала intro, затем главное меню  
- [ ] Видео с титрами воспроизводится со звуком (если есть в файле)  
- [ ] Enter / Space / Esc / ЛКМ — пропуск в меню  
- [ ] Дождаться конца ролика — переход в меню  
- [ ] «Новая игра» — как раньше, `main.tscn` + сцена 1  
- [ ] Временно переименовать `intro.ogv` — игра не зависает, сразу меню  
- [ ] Debug → выбор сцены — intro не мешает (запускается только при старте приложения)

## Конвертация MP4 → OGV (если понадобится другой источник)

```bash
ffmpeg -i input.mp4 -q:v 6 -q:a 6 -g:v 64 assets/video/intro.ogv
```

720p:

```bash
ffmpeg -i input.mp4 -vf "scale=-1:720" -q:v 6 -q:a 6 -g:v 64 assets/video/intro.ogv
```

## Риски и рекомендации

| Риск | Комментарий |
|------|-------------|
| Долгий intro при каждом F5 в редакторе | Нормально для релиза; при необходимости — флаг `DebugState.skip_intro` |
| CPU-декодирование Theora | На слабых ПК возможны подтормаживания |
| Дубликат ogv в корне | Можно удалить корневой файл после проверки, оставить только `assets/video/intro.ogv` |
| `.import` | Открыть проект в Godot один раз для генерации импорта видео |

- Сигнал окончания: `finished`
