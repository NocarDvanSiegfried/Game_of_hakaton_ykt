# Тест громкости — Сцена 1

Ручной чеклист для проверки настроек звука после Дня 4.

## Подготовка

1. Запусти игру (**F5**). Стартовая сцена — главное меню.
2. Открой **Настройки** → убедись, что ползунки отображают сохранённые значения.
3. Нажми **Сбросить** → значения: Общая 100%, Музыка 80%, Голоса 100%, Эффекты 75%, Фон 80%.

## Пресеты для проверки

Перед каждым пресетом: **Настройки** → выставить → **Назад** → **Новая игра**.

### A. Только голоса

| Категория | Значение |
|-----------|----------|
| Общая | 100% |
| Музыка | 0% |
| Голоса | 100% |
| Эффекты | 0% |
| Фон | 0% |

**Ожидание в scene1:** слышна только озвучка (рассказчик, Эбэ, Айсен, Кюннэй, Тонгус). Нет пурги, камина, SFX двери/лая.

### B. Только эффекты и фон

| Категория | Значение |
|-----------|----------|
| Общая | 100% |
| Музыка | 0% |
| Голоса | 0% |
| Эффекты | 100% |
| Фон | 100% |

**Ожидание:** атмосфера и SFX слышны, реплики без голоса (только текст).

### C. Всё выключено

| Категория | Значение |
|-----------|----------|
| Все | 0% |

**Ожидание:** полная тишина (включая меню при возврате).

### D. Общая на минимуме

| Категория | Значение |
|-----------|----------|
| Общая | 0% |
| Остальные | 100% |

**Ожидание:** тишина — Master глушит всё дерево bus.

## Точки контроля в scene1

| Момент | Что слушать |
|--------|-------------|
| Пролог | Голос рассказчика + `yakut_night` (Ambient) + SFX мороза |
| Дом бабушки | `fireplace` (Ambient), голос Эбэ, SFX рычания |
| Утро | `house_morning`, `stove_embers`, голоса Айсена/Кюннэй |
| Двор | `blizzard`, SFX двери, голоса |
| Погоня | `snow_run`, голос рассказчика |
| Прорубь / Тонгус | Ambient + SFX + `tongus_voice` |
| Финал (кукла) | `kunney_voice`, крик Айсена, ambient стихает |

## Персистентность

1. Выставь нестандартные значения (например, Голоса 40%, Эффекты 90%).
2. **Назад** → закрой игру (Выход).
3. Запусти снова → **Настройки** — значения должны совпасть.
4. **Новая игра** — громкость в сцене соответствует сохранённой.

## Регрессия

- [ ] Быстрый клик по диалогу не ломает озвучку (`DialogicVoiceStop`)
- [ ] Смена спикера не даёт наложения двух голосов
- [ ] Музыка меню реагирует на «Музыка» без перезапуска
- [ ] Esc закрывает настройки
- [ ] **O** во время scene1 открывает настройки; Dialogic на паузе; **O** / **Esc** закрывает
- [ ] Ползунки в игре меняют громкость ambient/voice в реальном времени
- [ ] **Сбросить** возвращает дефолты и слышно в игре
