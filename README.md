# Баргый: Путь сквозь Лёд — Сцена 1 (готовый пакет)

Этот пакет содержит работающий пролог Сцены 1 «Пурга» — от вступительного текста до прыжка Айсена в прорубь. Внутри — ~80 реплик, 3 точки выбора с последствиями, мини-битва с Тонгус Харахом.

## Что внутри

```
bargyy_scene1/
├── dialogic/
│   └── timelines/
│       └── scene1_timeline.dtl    ← весь сценарий Сцены 1
├── scenes/
│   └── main.tscn                  ← главная сцена Godot
└── scripts/
    └── main.gd                    ← скрипт запуска диалога
```

Скопируй из распакованного архива **три папки целиком**: `dialogic`, `scenes`, `scripts` — в корень проекта (рядом с `project.godot` и `addons`).

В Godot слева в файловой системе должно появиться:
```
res://
├── addons/
├── dialogic/
│   └── timelines/
│       └── scene1_timeline.dtl
├── scenes/
│   └── main.tscn

│   └── main.gd

```

Если что-то не появилось — правый клик на `res://` → **«Обновить файловую систему»**.

## Шаг 2. Создать 5 персонажей через Dialogic

В таймлайне используются 5 персонажей с короткими именами-ссылками. Их нужно создать через Dialogic UI (ты уже знаешь как — создавал `ebe`).

Открой вкладку **Dialogic → Character**. Для каждого персонажа:

1. Жми кнопку создания нового персонажа.
2. Сохрани в `res://dialogic/characters/` с указанным именем файла.
3. Заполни **Display Name** и **цвет** (Color).

### Список персонажей

| Файл | Display Name | Цвет (Hex) | Описание |
|------|--------------|------------|----------|
| `ebe.dch` | Бабушка Эбэ | `E8A95C` | Слепая сказительница. Тёплый янтарный. |
| `aisen.dch` | Айсен | `5B9BD5` | Мальчик 10 лет. Холодный голубой. |
| `kunney.dch` | Кюннэй | `F4C2D7` | Девочка 8 лет. Нежно-розовый. |
| `tongus.dch` | Тонгус Харах | `B8D4E3` | Мерзлый Глаз. Холодный ледяной. |
| `narrator.dch` | _(оставь пустым)_ | `AAAAAA` | Нарратор. Серый. Без отображаемого имени — для описаний. |

**Важно про `narrator`**: оставь поле Display Name пустым или впиши пробел. Тогда описательные тексты («Айсен бежит сквозь пургу...») будут отображаться без имени говорящего, как чистый нарратив.

После создания каждого персонажа жми **Ctrl+S**.

## Шаг 3. Указать стартовую сцену

1. В меню Godot: **Проект → Параметры проекта**.
2. В разделе **«Запустить»** (Run) найди поле **«Главная сцена»** (Main Scene).
3. Жми иконку папки справа → выбери файл `res://scenes/main.tscn` → **Открыть**.
4. Жми **«Закрыть»**.

---

## Шаг 4. Запустить!

Жми **F5** (или треугольник «Play» в правом верхнем углу).

Должно открыться диалоговое окно Dialogic с первой репликой нарратора:

> «Слушай, путник. Слушай так, как слушали мои предки тысячу зим назад...»

Кликай по экрану (или жми пробел) — диалог пойдёт дальше. В трёх местах появятся варианты выбора — выбирай мышкой.

## Возможные проблемы

### «Character 'ebe' not found»
Один из персонажей не создан или назван неправильно. Проверь, что файлы в `res://dialogic/characters/` называются точно: `ebe.dch`, `aisen.dch`, `kunney.dch`, `tongus.dch`, `narrator.dch`.

### Текст без имени говорящего идёт от нарратора, но имя «narrator» всё равно показывается
Открой `narrator.dch` → сотри Display Name полностью (или поставь пробел) → Ctrl+S.

### Таймлайн не открывается / показывает ошибку парсинга
Открой `scene1_timeline.dtl` в Dialogic → Timeline → если не парсится визуально, переключись справа сверху на **«Text Editor»** — там содержимое будет точно как в файле, и Dialogic покажет красным проблемную строку.

### Диалоговое окно не появляется
Проверь, что плагин Dialogic включён: **Проект → Параметры проекта → Модули** → галочка у Dialogic.
